# 답변 평가·차단 정책

Agent는 문장을 반환하기 전에 질문 유형별 필수 요구사항, 숫자 grounding, 주장별 근거,
공시 인용, secret 노출을 검사한다. 검증 결과는 `validation.checks`에 공개한다.

## 질문 유형별 핵심 요구사항

- 재무지표: 기업, 기간, 지표, 값, 단위, 연결/별도 기준, 공시 근거
- 투자계획: 연간 계획, 세부 투자 유형, 분기 실적과 계획의 구분, 단위, 근거
- 설비투자 비교: 두 기업, 같은 기간, 비교 가능한 통화·단위, 양사 값, 근거
- 자금조달: 요청한 유상증자/CB/BW/EB, 결정 기준, 실제 완료와의 구분, 근거 또는 명시적 부재
- 계약 해지: 원계약 검색 범위, 후속 해지 검색, 연결 식별자와 신뢰도, 근거 또는 명시적 부재
- 사업 변화: 두 연도 각각의 사업 섹션 근거, 공통/추가 강조/강조 감소 구분, 중단 단정 금지
- 정정: 원본, 정정 전, 정정 후, 현재 유효 값 또는 안전한 미연결 고지

## Action

- `allow`: 모든 필수 검사를 통과한 답변
- `blocked`: 수치 또는 필수 근거가 검증되지 않아 초안을 차단
- `clarify`: 회사·기간·비교 대상·지표가 부족하거나 모호하여 구체적으로 역질문
- `limit`: 코퍼스 범위 밖이거나 필요한 공시 유형이 없어 한계를 고지
- `review`: 자동 검토 결과 통과로 확정하지 못한 상태

모든 정상 답변은 접수번호를 포함한 citation을 유지한다. Context에 없는 수치나 계산 결과는
답변에 허용하지 않으며, 계산은 입력값·식·결과·evidence ID로 재현할 수 있어야 한다.
