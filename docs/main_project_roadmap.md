# 공시 AI Agent 메인 프로젝트 로드맵

이 저장소는 주최 측이 제공한 전체 공시 4,204건을 대상으로 한다. 초기 XML 샘플 분석은 종료했으며,
현재 개발 기준 데이터베이스는 `outputs/disclosures.db`이다.

## 현재 완료 범위

- 정기·주요사항·거래소·지분공시 전체 구조화
- 문서·섹션·본문·표·셀·이벤트·정정 이력 저장
- 메타데이터 필터 + FTS5 + 정형 셀 검색
- 단위·기간·연결/별도 기반 계산
- 6대 핵심 질의 전용 실행 경로
- FastAPI `/answer`와 Swagger UI
- 복합 질의 planner, 근거 재정렬·다양성 제어, 재무지표 ontology
- 단위·통합 테스트 92개, base 37개에서 파생한 robustness 평가 150개
- 강한 골드 50개, 산업 확장·충돌·한계 40개, DB-원문 감사 30개, API 런타임 12개

## HyperCLOVA 연동 전 완료 상태

1~7단계 구현을 완료했다. 현재 Swagger에서는 결정론적 검색·수치 계산·lifecycle·정정·사업 변화
비교와 Evaluation Guardrail을 확인할 수 있다. 8단계 실제 HyperCLOVA endpoint/key 통합은 진행하지 않았다.

## HyperCLOVA 연동 전 개발 순서

### 1. 메인 프로젝트 정리

- 초기 분석 보고서와 개발용 DB 제거
- Parser 샘플 검증 코드는 회귀 테스트로 유지
- 메인 상태·평가 정책·지표 정의 문서 통합

### 2. Evaluation Guardrail

완료.

- 응답에 `claims`, `calculations`, `citations`, `limitations`, `confidence`, `validation` 추가
- 숫자·단위·기간·scope·근거 검증
- 검증 실패 응답 차단

### 3. 질문 유형별 요구사항과 정보한계 대응

완료.

- 6개 질문 유형별 필수 근거와 필수 답변 항목 정의
- 누락·충돌·모호성 reason code
- 안전한 거절 또는 구체적인 역질문

### 4. 자금조달 lifecycle

완료. 제공 코퍼스에 납입 완료·발행 결과 공시 유형이 없으면 결정금액만 제시하고 완료를 단정하지 않는다.

- 결정 → 정정 → 발행가 확정 → 납입 → 발행 결과 → 철회 연결
- 결정금액과 실제 조달 완료 금액 구분

### 5. 계약 lifecycle

완료. 정정본 중복 제거, 관련공시일 우선 연결, 일부/전체 해지와 연결 신뢰도를 제공한다.

- 체결 → 금액·기간 변경 → 정정 → 일부/전체 해지 연결
- 관련 공시번호, 계약명, 상대방, 계약일, 금액 기반 chain 생성

### 6. 정정공시 통합

완료. 명시적 원본 ID가 없을 때 이벤트 결정일 등을 사용하되 추론 신뢰도와 미연결 상태를 노출한다.

- 네 공시군의 original/correction/current effective 관계 통합
- 현재값·최초값·정정 전후 질문을 명시적으로 분기

### 7. 사업 변화 검색 고도화

완료. 8개 근거 분류와 연도별 사업 신호 프로필을 원문 청크에 연결한다.

- 두 연도의 동일 사업 섹션을 비교
- 제품, 사업부문, 매출 구성, 신규·중단 사업, R&D, 투자, 시장 변화 근거 선택
- 본문 의미 검색은 선택적으로 추가하되 숫자는 structured cell을 재조회

### 7.1. HyperCLOVA 연동 전 추가 성능 개선

완료.

- 하나의 질문에 복수 지표 또는 수치 계산+정성 비교가 함께 있으면 독립 subtask로 분해하고 모두 검증
- FTS 점수, 질의 단어 coverage, section 일치, 구조화 근거 선호를 공개 가능한 점수로 재정렬
- 동일 문서·섹션의 유사 근거가 상위 결과를 독점하지 않도록 결과 다양성 제어
- 재무지표 alias, 선호 재무제표, 부호 해석을 단일 ontology로 통합
- base 37개 질의를 wrapper·인용 요구·표현 변형으로 확장한 150개 robustness 평가

### 8. HyperCLOVA 연동

이번 개발 범위 밖이다. 위 검증 계층을 통과한 구조화 사실만 문장 생성에 제공한다.

## 공통 완료 기준

- 모든 정상 답변에 근거 공시 표시
- 모든 숫자가 원문 셀 또는 재현 가능한 계산과 연결
- 비교 입력이 불완전하면 순위·증감을 생성하지 않음
- 계획·실적·결정·완료를 구분
- 근거가 부족하면 한계 고지 또는 구체적인 역질문
- 기존 단위 테스트와 golden 질의 회귀 통과
- 각 단계 완료 시 Swagger 실제 질의 확인
