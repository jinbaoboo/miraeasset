# 메타모픽 QA 100문항 실제 API 검증

## 목적

동일한 공시 질문에 명시적인 제외 회사·제외 연도를 섞었을 때 시스템이 이를 검색 대상으로
오인하지 않는지 검증했다. `close` 50개와 `open` 50개를 2개씩 묶어 총 50개의 의미 동일
질문쌍으로 구성하고, 실행 중인 FastAPI의 `GET /answer`에 실제 HTTP 요청으로 전송했다.

## 기존 평가보다 강화한 항목

- `[제외 조건: 삼성전자, 2022년]`처럼 질문 앞에 붙은 부정 메타데이터
- `(비교 금지=삼성전자; 참조 금지=2022년)`처럼 질문 뒤에 붙은 부정 메타데이터
- 영문 회사명·종목코드·축약 기간과 제외 조건이 동시에 있는 입력
- 예상 회사와 연도의 포함 여부가 아닌 정확한 집합 일치
- 답변별 수치·단위·scope·기간·접수번호·citation 필드 검사
- 질문쌍 사이의 validation action, query type, 회사, 연도, 분기, 지표, scope,
  인용 문서 집합 일치

생성기는 `eval/build_metamorphic_qa_100.py`이며, 100개 고유 문항과 50개 질문쌍,
기존 질문과의 완전 일치 0개를 실행 시 검증한다.

## 실행

```bash
DISCLOSURE_DB=outputs/disclosures.db \
  .venv/bin/uvicorn src.api.app:app --host 127.0.0.1 --port 8000

make eval-metamorphic-http \
  PYTHON=.venv/bin/python \
  BASE_URL=http://127.0.0.1:8000
```

평가 결과의 `transport`는 `http`로 기록된다. 질문별 실제 답변, 개별 check와 질문쌍
일관성 check는 `eval/metamorphic_qa_100_results.json`에 보존한다.

## 발견 및 개선 과정

| 단계 | 개별 문항 | 일관 질문쌍 | 발견 사항 |
|---|---:|---:|---|
| 최초 실제 HTTP 기준선 | 0/100 | 44/50 | 제외 회사·연도를 긍정 필터로 인식 |
| 제외 조건 정규화 후 | 98/100 | 49/50 | 개별 답변은 정상화됐으나 NC 질문쌍의 인용 문서 불일치 |
| 대표 보고서 인용 개선 후 | 100/100 | 50/50 | 전체 통과 |

질의 분석기는 대괄호·괄호로 명시된 제외 컨테이너만 메타데이터 추출에서 제거한다.
따라서 `외부 지식과 표지 문구는 제외해` 같은 일반 요청 문장은 그대로 유지한다.

분기가 지정되지 않은 연도별 사업 요약은 같은 연도의 여러 분기 보고서를 섞지 않고 가장
최근 보고서 한 건을 대표 근거로 선택한다. 답변에 사용하지 않은 다른 분기 문서가 citation에
붙는 현상을 제거해 표면 표현이 달라도 동일한 접수번호를 제공한다.
