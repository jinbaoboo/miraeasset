# 지표·사건 정의 정책

- 매출액·영업이익·당기순이익·자산·부채·자본은 요청한 연결/별도 scope와 기준기간을 우선한다.
- 설비투자는 기본적으로 현금흐름표의 `유형자산의 취득` 현금유출 절대값을 사용한다. 서로 다른 정의는 자동 비교하지 않는다.
- 투자계획 표의 연간 계획과 분기 실적은 서로 다른 상태이며, 분기 실적/연간 계획으로 계산한 값만 집행률로 표시한다.
- 유상증자·CB·BW·EB의 발행결정 금액은 계획·결정 금액이다. 예정 납입일만으로 실제 조달 완료를 판정하지 않는다.
- 계약 정정본은 하나의 원계약 chain으로 집계한다. 해지 공시는 관련공시일을 우선하고 계약명·상대방·계약기간을 보조한다.
- 정정 질문의 current effective는 같은 정정 항목에서 가장 최근 정정본의 비어 있지 않은 after 값을 사용한다.
- 사업 변화의 ‘추가/감소’는 비교한 사업 섹션의 강조 표현 변화이며 신규 진출·사업 중단을 자동으로 뜻하지 않는다.

지표 정의의 실행 기준은 `src/domain/metric_ontology.py` 한 곳에서 관리한다. 현재 손익계산서의
매출액·매출총이익·영업이익·당기순이익·EPS, 재무상태표의 자산·부채·자본·현금및현금성자산·
재고자산·유형/무형자산·차입금, 현금흐름표의 영업/투자/재무활동 현금흐름과 설비투자,
그리고 연구개발비·계약금액·계약비율·보유비율을 구분한다. 새로운 alias를 추가할 때는
질의 분석과 표 셀 ranking 양쪽에 자동 적용되며, 더 긴 고유 지표명을 짧은 포함어보다 우선한다.

값, 단위, 기간, scope 중 하나라도 비교에 필수인데 확인되지 않으면 `unknown`을 유지하고 계산·순위를 만들지 않는다.
