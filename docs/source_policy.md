# Source policy

1. 답변 사실과 숫자의 출처는 제공 corpus 내부 파일만 허용한다.
2. 모델의 사전지식은 검색 계획과 문장 표현에만 사용한다.
3. 근거가 없는 값은 생성하지 않고 확인 불가로 응답한다.
4. raw 파일은 읽기 전용이며 모든 복구는 메모리에서 수행한다.
5. 파생 레코드는 `doc_id`, `rcept_no`, source file, locator를 유지한다.
6. 현재 상태 질문은 명확히 연결된 최신 유효본을 우선한다.
7. 계산 결과는 입력값, 단위, 공식과 함께 기록한다.
8. 지분공시의 개인 식별정보는 검색·로그·응답에서 최소화한다.
9. 외부 웹, 뉴스, OpenDART runtime, 다른 LLM은 답변 근거로 사용하지 않는다.
